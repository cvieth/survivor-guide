# Mitmachen

Das Projekt wird über Issues und Pull Requests im [öffentlichen GitHub-Repository](https://github.com/cvieth/survivor-guide) gepflegt.

## Vorgehen

1. Vorhandene Themen prüfen und ein Issue eröffnen.
2. Neues Markdown-Dokument aus der [Artikelvorlage](https://github.com/cvieth/survivor-guide/blob/main/templates/artikel.md) erstellen.
3. Quellen, Risiken und Grenzen angeben.
4. Review und technische Tests abwarten.
5. Änderungen gemeinsam verbessern.

Weitere Informationen: [CONTRIBUTING.md](https://github.com/cvieth/survivor-guide/blob/main/CONTRIBUTING.md).
